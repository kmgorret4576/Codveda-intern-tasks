# 📊 Data Analytics Datasets

Welcome to my data analytics dataset repository.

This repository contains datasets used for practicing and demonstrating data analysis, data cleaning, statistical analysis, visualization, and machine learning concepts.

## 📁 Datasets

### 1. 📉 Churn Dataset
The Churn dataset contains customer-related information that can be used to analyze customer churn.

**Possible analysis areas:**
- Customer churn rates
- Customer behavior
- Service usage
- Customer service interactions
- International and voicemail plans
- Factors associated with customer churn
- Data visualization and statistical analysis

**File:** `churn.csv`

---

### 2. ⚠️ Risk Dataset
The Risk dataset can be used to explore and analyze risk-related information and identify patterns or factors associated with different levels of risk.

**Possible analysis areas:**
- Risk classification
- Risk factors
- Data cleaning and transformation
- Statistical analysis
- Data visualization
- Predictive analytics

**File:** `risk.csv`

---

### 3. 💬 Sentiment Dataset
The Sentiment dataset contains text or sentiment-related data that can be used to explore opinions, emotions, and sentiment patterns.

**Possible analysis areas:**
- Sentiment classification
- Positive, negative, and neutral sentiment
- Text data analysis
- Data preprocessing
- Sentiment visualization
- Natural Language Processing (NLP)

**File:** `sentiment.csv`

---

The purpose of this repository is to build practical experience in:
